# โปรเจกต์

โปรเจกต์วิศวกรรมที่พัฒนาโดย DOJOJIN.TECH

## Vigil Platform

ระบบ CCTV analytics แบบ on-premise รองรับกล้องหลายยี่ห้อ ติดตามสถานะแบบ real-time แจ้งเตือนผ่าน LINE และ Telegram และบริหารข้อมูลตามมาตรฐาน PDPA

- [Vigil Platform](./vigil-platform) — Dashboard, analytics, alerting, และความปลอดภัย
- [Vigil Mobile](./vigil-mobile) — แอปมือถือ iOS & Android

## HippoCraft

โปรแกรมอ่านและแก้ไข PDF โอเพนซอร์สเขียนด้วย Rust ต่อยอดจาก PdfCraft พร้อมภาษาไทยที่โปรแกรมอื่นมักข้าม

- [HippoCraft](./hippocraft) — แก้ข้อความไทยในไฟล์เดิม · OCR ไทยบนเครื่อง · ฝังฟอนต์ไทยถูกต้อง

## AI OCR Pipeline

- [AI OCR Pipeline](./ai-ocr-pipeline) — ดึงข้อมูลเอกสารอัตโนมัติผ่าน Google Apps Script *(หยุดพัฒนาชั่วคราว)*

## AI Stack (Local LLM)

ระบบ AI inference แบบ self-hosted รันทั้งหมดบน consumer GPU — ไม่มี cloud subscription ไม่มีข้อมูลออกนอกเครื่อง

- [AI Stack](./ai-stack) — Ollama, Open WebUI, SearXNG, Continue.dev และการเลือกโมเดลสำหรับ GPU VRAM 6 GB
