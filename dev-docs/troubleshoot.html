Port 3000 / Service ขึ้นไม่ได้

อาการวิธีแก้
Port 3000 ถูกใช้ไปแล้ว (EADDRINUSE) 
lsof -i :3000      # หา PID
kill -9 <PID>     # kill process เก่า
pm2 restart api-server
Docker container ไม่ขึ้น 
docker ps -a       # ดู status
docker logs vigil-postgres  # ดู error
docker compose up -d --force-recreate
