Architecture & Stack Decisions

ทำไมต้อง Vanilla JS ไม่ใช้ React / Vue / Svelte?

เป็น deliberate decision ถาวร (DECISIONS.md #1) — ไม่มี build step = เปิดไฟล์แก้ได้เลย, ไม่มี dependency hell, bundle size เล็ก, dashboard ทำงานได้แม้ Node ตายชั่วคราว (static files serve ได้จาก nginx/CDN). Dashboard = งานวิเคราะห์ไม่ใช่ interactive app ที่ต้องการ component reactivity ซับซ้อน

อ้างอิง: DECISIONS.md #1

ทำไม auth ต้องมี 3 layer (cookie + localStorage + sessionStorage)?

Safari ITP (Intelligent Tracking Prevention) บล็อก cross-site cookie เมื่อเข้าผ่าน Cloudflare Tunnel — ถ้าใช้แค่ cookie, Safari users login ไม่ได้. Triple-layer: server-side session cookie + localStorage token + sessionStorage fallback ครอบคลุม browser policy ทุก variant

อ้างอิง: GOTCHAS #2 · DECISIONS.md #2

ทำไมไม่ใช้ ORM (Prisma / Drizzle / Sequelize)?

Raw SQL เพียงพอสำหรับ scale นี้ — ORM เพิ่ม complexity layer โดยไม่ได้ประโยชน์ชัดเจน. Query ที่ซับซ้อน (date_bin density, analyticsEventClause, EXPLAIN tuning) อ่านง่ายกว่าในรูป SQL ตรงๆ และ debug ง่ายกว่ามาก

อ้างอิง: DECISIONS.md #3

ทำไม EMQX แทน Mosquitto?

Bosch IVA (firmware เก่า) ส่ง MQTT packet แบบที่ Mosquitto 2.x strict validator reject — camera reconnect ทุก 30–300 วินาที log ว่า "disconnected due to malformed packet". EMQX 5.8 tolerant กว่า ไม่มี config knob ให้ relax ใน Mosquitto

อ้างอิง: GOTCHAS #33 · DECISIONS.md #112

PM2 & Services

ทำไม restart PM2 แล้วกล้อง Bosch disconnect / EHOSTUNREACH?

macOS Local Network Privacy (LNP) — process ที่ spawn จาก terminal ที่ไม่ใช่ macOS GUI จะไม่ได้ LNP permission → เมื่อ PM2 restart และ spawn child process ใหม่, child ไม่มี LNP → EMQX broker บน LAN เข้าไม่ได้ (EHOSTUNREACH). ต้องรัน restart จาก macOS GUI Terminal ผ่าน .command script เท่านั้น

อ้างอิง: Restart Services (LNP) · GOTCHAS #84

Schema & Migration

Migration fail แล้ว api-server ไม่ start — ทำยังไง?

By design — failing migration abort startup ทันที (GOTCHAS #19). ห้าม comment out migration หรือ try/catch ครอบ. แนวทาง: (1) restore backup ล่าสุด, (2) แก้ SQL ให้ handle live schema จริง, (3) restart

./scripts/restore.sh backups/vigil_platform_<latest>.dump
# แก้ db/db_migration_NNN_xxx.sql
pm2 restart api-server
pm2 logs api-server --lines 30

อ้างอิง: GOTCHAS #19 · Recipe: เพิ่ม Migration

Migration numbering ต้องทำยังไง — มีกฎอะไรบ้าง?

ใช้ 3-digit prefix เสมอ (เช่น db_migration_046_my_feature.sql) เพราะ runner sort ตาม filename. Migration ต้องเป็น idempotent (IF NOT EXISTS, ADD COLUMN IF NOT EXISTS, ON CONFLICT DO NOTHING). ตรวจ next number ก่อนสร้างไฟล์ใหม่ทุกครั้ง

ls db/db_migration_*.sql | tail -5   # ดู number ล่าสุด

อ้างอิง: GOTCHAS #18 · Recipe: เพิ่ม Migration

Camera Configuration

เพิ่มกล้องแล้ว events ไม่เข้า — camera_id ถูกต้อง?

ตรวจ invisible characters ใน camera_id — เกิดจากพิมพ์ด้วย keyboard ภาษาไทย (Thai phinthu U+0E3A prepend, invisible to the eye). POST /api/cameras ตอนนี้ sanitize แล้ว แต่ถ้า config เก่า อาจมีค่าผิด

# ตรวจ camera_id ใน config
node -e "
const c = require('./config/cameras-config.json');
c.forEach(cam => console.log(JSON.stringify(cam.camera_id), cam.camera_id.length));
"

อ้างอิง: GOTCHAS #32

Mapping rule ตั้งแล้วแต่ category ยังเป็น 0 — เช็คอะไร?

Bosch LineDetector event มี object_class แต่ไม่มี state — ถ้า mapping rule ตั้ง match_state='true' จะ miss events ทั้งหมด. สำหรับ "นับทุก crossing" ให้ตั้ง State เป็น (any) (NULL)

อ้างอิง: GOTCHAS #9 · SKILL.md §3

i18n & UI

เพิ่ม string ใน th: แล้ว English mode เห็น "undefined"

ต้องใส่ key ทั้ง th: และ en: block พร้อมกันเสมอ — ขาด en: → I18N.t() return undefined เมื่อ user เปลี่ยน language (GOTCHAS #42)

อ้างอิง: GOTCHAS #42 · Recipe: เพิ่ม i18n String

Health Report PNG abort — Node.js crash / "Could not load fallback font"

SVG text ที่ render ผ่าน sharp มี emoji → librsvg/Pango abort เพราะไม่มี emoji font. ใช้ report-renderer._svgSafeText() strip emoji ก่อนใส่ใน SVG template เสมอ. LINE alert และ dashboard HTML ใช้ emoji ได้ (คนละ render path)

อ้างอิง: GOTCHAS #25a · DECISIONS.md #144, #148

Mobile layout พัง — horizontal scroll ทั้งหน้า

CSS Grid item ที่มี content กว้าง (table ยาว, canvas) ไม่ shrink เพราะ min-width: auto. แก้: ใส่ min-width: 0 ที่ grid child. เริ่มจาก html, body { overflow-x: hidden } แล้วค่อย trace element ที่ overflow

อ้างอิง: GOTCHAS #29, #30, #31

Database / Reports

pg_dump backup ดูไม่ได้ — cat แล้วเห็น binary garbage

pg_dump -Fc สร้าง custom-format archive ไม่ใช่ plain SQL. ดู TOC ด้วย pg_restore --list backup.dump หรือแปลงเป็น plain SQL ด้วย pg_restore -f output.sql backup.dump

อ้างอิง: GOTCHAS #20

License ไม่ enforce ในตอน dev — ปกติไหม?

ปกติ — ถ้า LICENSE_PUBLIC_KEY ใน .env ยังเป็น placeholder, middleware detect ด้วย isPublicKeyConfigured() แล้ว bypass enforcement เพื่อไม่ให้ dev locked out ตัวเอง. Production deployment จะมี key จริง

อ้างอิง: GOTCHAS #27 · src/license.js
