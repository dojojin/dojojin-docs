10 Maps API (API แผนที่)

เทคโนโลยี: OpenLayers 9.2.4 (ไม่ใช่ Mapbox)

แก้ไข: เอกสารนี้เคยระบุ Mapbox ซึ่งไม่ถูกต้อง Vigil ใช้ OpenLayers สำหรับหน้าแผนที่ โดยใช้ CartoDB เป็นผู้ให้บริการไทล์ OpenLayers มีประสิทธิภาพ เป็นโอเพนซอร์ส และไม่ต้องใช้ token การค้นหาเชิงพาณิชย์ หรือการอนุมัติ

คุณสมบัติแผนที่

เครื่องหมายกล้อง

  • กล้องแต่ละตัว = เครื่องหมายบนแผนที่ (lat/lng จากการตั้งค่า)
  • การเข้ารหัสสีตามสถานะ: เขียว (ออนไลน์) แดง (ออฟไลน์) เหลือง (คำเตือน)
  • คลิกเครื่องหมาย → รายละเอียดกล้อง + รูปภาพสด + เหตุการณ์ล่าสุด
  • ลากเครื่องหมายเพื่ออัปเดตตำแหน่งกล้อง

การจัดกลุ่ม

  • ที่ระดับซูมต่ำ (<15): จัดกลุ่มเครื่องหมาย (เช่น "42 cameras" ในวงกลม)
  • ซูมเข้า → กลุ่มแตกออกเป็นกลุ่มย่อย
  • ลดความรก ภาพสำหรับการปรับใช้ขนาดใหญ่ (100+ cameras)
  • การจัดกลุ่มอัตโนมัติเมื่อข้อมูลเปลี่ยนแปลง

แผนที่ความร้อน

  • สลับมุมมอง: ความหนาแน่นของเหตุการณ์ต่อภูมิภาค (24 ชั่วโมงล่าสุด)
  • พื้นที่ร้อนแสดงบริเวณที่มีข้อกังวลด้านความปลอดภัย (จุดร้อนของการเคลื่อนไหว บริเวณที่อาจจะมีการบุกรุก)
  • ลำดับสี: น้ำเงิน (ต่ำ) → แดง (กิจกรรมสูง)
  • อัปเดตแบบเรียลไทม์เมื่อมีเหตุการณ์ใหม่

Live Pulse (พัลส์สด)

  • เมื่อเหตุการณ์เกิดขึ้น: พัลส์แอนิเมชันขยายจากเครื่องหมาย (v1.5.0+)
  • ข้อมูลย่อมูลทางสายตา: "การกระทำเกิดขึ้นที่นี่เดี๋ยวนี้"
  • ระยะเวลาพัลส์: 3 วินาทีแล้วค่อยๆ หายไป
  • สามารถแก้ไขได้ (ผู้ใช้สามารถปิดได้เพื่อประสิทธิภาพ)

ผู้ให้บริการไทล์

  • หลัก: CartoDB Positron (สะอาด มีการระบุแหล่งที่มา)
  • ทางเลือก: CartoDB Voyager (รายละเอียด ไม่ยุ่งยาก)
  • OSM: OpenStreetMap (สำรอง ฟรี)
  • ดาวเทียม: Mapbox Satellite (ไม่บังคับ ต้องใช้ token, v1.5.1+)

ตัวควบคุม

  • ปุ่มซูมเข้า/ออก (+ เลื่อนวงล้อม)
  • รีเซ็ตมุมมอง (จุดศูนย์กลาง + ซูมเริ่มต้น)
  • สลับแผนที่ความร้อน
  • สลับมุมมองดาวเทียม
  • ตัวเปลี่ยนเลเยอร์ (หากเปิดใช้งานผู้ให้บริการหลายราย)

การรวม WebSocket แบบเรียลไทม์

เมื่อเหตุการณ์เกิดขึ้นในระบบ:

1. Backend publishes to Redis: { type: 'event', camera_id: 3, lat: 13.7, lng: 100.5, event_type: 'motion' }
2. WS server broadcasts to all connected map page clients
3. Frontend receives:
   - Add pulse animation at (lat, lng)
   - Update marker color (if camera was offline)
   - Increment heatmap count at position
4. Pulse fades after 3s (CSS animation)
5. Heatmap updates in real-time

Tile Proxy และความปลอดภัย (v1.5.1)

ไทล์ Mapbox ต้องมี authentication token เพื่อป้องกันการรั่วไหลของ token ให้กับไคลเอ็นต์:

  • เดิม (v1.5.0): Mapbox token ในโค้ด frontend → เปิดเผยในแท็บเครือข่าย
  • ใหม่ (v1.5.1): Backend proxy endpoint /api/tiles/mapbox/:z/:x/:y.png
  • การไหลของคำขอ: Frontend → Backend → Mapbox API → PNG bytes → Frontend
  • ขีดจำกัดอัตรา: 100 tiles/นาที ต่อ IP (ป้องกันการใช้ผิด)
  • การแคช: Redis cache ไทล์เป็นเวลา 7 วัน (ลดคำขอ Mapbox)

การจัดการตำแหน่งกล้อง

ไหลของ UI

  1. ผู้ดูแลระบบไปที่ Settings (การตั้งค่า) → Cameras (กล้อง)
  2. ขยายการตั้งค่ากล้อง คลิกปุ่ม "Set Location" (ตั้งตำแหน่ง)
  3. เปิด Map modal ผู้ใช้คลิกเพื่อวางเครื่องหมาย
  4. ยืนยัน → บันทึก lat/lng ลงตาราง cameras
  5. หน้าแผนที่รีเฟรชทันที (WebSocket update)

นำเข้าจากอุปกรณ์ GPS

(Roadmap Ph.5) — อนุญาตให้อัปโหลด CSV ที่มีพิกัด GPS เพื่อตั้งค่าตำแหน่งกล้องแบบกลุ่ม

การเพิ่มประสิทธิภาพประสิทธิการ

การเพิ่มประสิทธิภาพ ผลกระทบ สถานะ
Tile caching (Redis) ลดคำขอ Mapbox 80% v1.5.1
Clustering library (fast-cluster) 50+ กลุ่มกล้องใน <100ms v1.4.0
WebSocket debounce (pulse events) ข้ามพัลส์ที่ซ้ำกันภายใน 500ms v1.5.0
Heatmap grid size optimization Heatmap render <1s แม้มีเหตุการณ์ 10,000+ เหตุการณ์ v1.5.1
Lazy load map (เฉพาะเมื่อแท็บมองเห็นได้) ลด JS eval จนกว่าผู้ใช้จะนำทางไปยังแผนที่ v1.4.5

แผนที่มือถือ (Responsive)

  • ≤768px: แผนที่เต็มจอ (ไม่มี sidebar ควบคุมที่ด้านบน)
  • แตะเครื่องหมาย: เลื่อนแผ่นด้านล่างขึ้นพร้อมรายละเอียดกล้อง + รูปภาพสด
  • Pinch zoom: รองรับ native touch gesture
  • Responsive tiles: โหลดความละเอียดสูงบนหน้าจอ high-DPI

แผนงานในอนาคต

คุณสมบัติ ระยะ คำอธิบาย
Geofencing Ph.5 วาดโซนบนแผนที่ แจ้งเตือนหากบุคคล/ยานพาหนะเข้า/ออก
Path history (ประวัติเส้นทาง) Ph.5 แสดงการติดตามบุคคลข้ามมุมมองกล้องหลายแห่ง
Camera grouping overlay Ph.6 กล่องกลุ่มภาพ (เช่น polygon "North Building")
Multi-map support (รองรับแผนที่หลายแบบ) Ph.6 ลูกค้ามีหลายตำแหน่ง = แผนที่แยก

การแก้ปัญหาแผนที่

หากแผนที่ว่าง: (1) ตรวจสอบ browser console เพื่อหาข้อผิดพลาด, (2) ยืนยันว่าเซิร์ฟเวอร์ไทล์สามารถเข้าถึงได้, (3) ยืนยัน lat/lng ของกล้องในฐานข้อมูล (ไม่เป็น null), (4) ล้างแคช + โหลดซ้ำ
