01 จุดประสงค์โครงการ

ทำไมถึงชื่อ "Vigil Platform"

Vigil / ˈvɪdʒ.ɪl / — n. การเฝ้าระวัง · การตื่นตัวตลอดคืน · ยามเฝ้า

ในภาษาอังกฤษ "vigil" หมายถึงช่วงเวลาที่ต้องตื่นตัว เฝ้าดูโดยไม่หลับ — ตรงกับสิ่งที่ระบบนี้ทำ: เฝ้าระวัง 24 ชั่วโมงต่อวัน 7 วันต่อสัปดาห์ ไม่มีวันหยุด รับ event จากกล้องทุกยี่ห้อ วิเคราะห์ แจ้งเตือน และบันทึกโดยอัตโนมัติ ไม่ต้องพึ่งคนเฝ้าตลอดเวลา

ชื่อเดิมของ platform นี้คือ bosch-mqtt-dashboard — ตั้งตามยี่ห้อกล้องที่รองรับ ณ ตอนเริ่มต้น เมื่อ platform พัฒนาเป็น multi-vendor รองรับ Bosch, Hikvision, Dahua และ ONVIF ทั่วไป การใช้ชื่อผูกกับ vendor เดียวกลายเป็นปัญหาสำหรับการ white-label และการขยายตลาด จึงเปลี่ยนชื่อเป็น Vigil Platform ใน v1.5.0 — ชื่อที่ vendor-neutral, ตลาดระดับ enterprise เข้าใจได้ทันที และสะท้อน mission ของระบบอย่างตรงไปตรงมา

ปัญหาที่ต้องแก้ไข

ตลาด CCTV ในไทยและเอเชียตะวันออกเฉียงใต้ยังพึ่งพาสถาปัตยกรรมที่ขาดความยืดหยุ่นในหลายด้าน:

  • Bosch IVA Pro + Cloud: ตรวจจับ event ได้ดี แต่บังคับให้ส่งข้อมูลผ่าน Bosch cloud ซึ่งมีค่าใช้จ่ายรายเดือนที่ไม่มีเพดาน และล็อกข้อมูลไว้กับ vendor
  • ไม่รองรับ LINE: ลูกค้าไทยคาดหวัง LINE notification เป็นมาตรฐาน แต่ Bosch ไม่มีการรองรับ native
  • PDPA: ข้อมูล event และภาพวิดีโอถูกเก็บบน server ต่างประเทศ — compliance risk สำหรับองค์กรไทย
  • ไม่มี source code ownership: ลูกค้าต้องพึ่ง vendor ทุกอย่าง ปรับแต่งระบบเองไม่ได้
  • White-label ไม่ได้: Bosch ไม่อนุญาตให้ SI หรือ reseller ขายต่อด้วยแบรนด์ของตัวเอง
  • Multi-vendor ไม่ได้: dashboard ของ vendor แต่ละรายดูได้เฉพาะกล้องยี่ห้อตัวเอง — ไม่มีที่เดียวสำหรับกล้องผสมยี่ห้อ

วิธีแก้ไข

Vigil Platform คือระบบ CCTV analytics แบบ self-hosted ที่ออกแบบมาตอบปัญหาข้างต้นโดยตรง:

สำหรับลูกค้า

  • ไม่มี vendor lock-in — ข้อมูลและ infrastructure อยู่บน server ของลูกค้า 100%
  • LINE notification พร้อมภาพ snapshot ส่งถึงแชท/กลุ่มที่กำหนด
  • ไม่มีค่ารายเดือน cloud — จ่ายครั้งเดียว + MA รายปี
  • PDPA compliant by design — เก็บข้อมูลในไทย ลบอัตโนมัติตามนโยบาย
  • Source code ownership — ปรับแต่งได้ภายใต้ใบอนุญาต
  • Multi-vendor CCTV — Bosch, Hikvision, Dahua, ONVIF บน dashboard เดียว

สำหรับ Partners และ Resellers

  • White-label ready — โลโก้ สี ชื่อ brand ปรับได้ต่อลูกค้า
  • Margin สูงกว่า SaaS rental — รายได้แบบ one-time + MA รายปี
  • MA = recurring income — support และ patch ต่อเนื่อง
  • ยืดหยุ่นในการเจรจาราคา — ไม่มี fixed tier บังคับ
  • Branding control — ลูกค้าปลายทางเห็นแบรนด์ SI ไม่ใช่ "Vigil"

สิ่งที่ทำได้ — ภาพรวม

Vigil Platform ครอบคลุม 6 กลุ่มหลักที่ทำงานร่วมกัน ดูรายละเอียด feature matrix เต็มได้ที่ 02 สิ่งที่ทำได้

รับ Event หลายยี่ห้อ

Dashboard เดียว รองรับ 4 ระบบกล้องพร้อมกัน ผ่าน ingester สถาปัตยกรรมแยก — alert engine, stats, reports และ UI ไม่มีโค้ดเฉพาะ vendor เลย

  • Bosch — MQTT (ONVIF Profile M), IVA Pro / IVA Basic
  • Hikvision — ISAPI Alert Stream: Smart Events + Face Capture
  • Dahua — HTTP CGI: Smart Events, IPC Event Manager

LINE Alerts

ส่ง notification ไปยัง user, group, room ผ่าน LINE Official Account + Bot API — รวมภาพ snapshot, event detail, timestamp, camera name ทั้งสองภาษา (TH/EN)

Mobile App (iOS/Android)

Native React Native companion app — real-time alerts, event list, live map, push notifications, biometric auth, custom server URL

Analytics & Reports

Executive Summary dashboard (KPI, trends), Health Report (SVG+PNG), timeline analysis, uptime tracking, custom SQL queries

Smart Map

OpenLayers map với CartoDB tiles, clustering, heatmap, camera location markers, live pulse, geofencing (roadmap)

Appearances Analytics

Forensic search และ behavioral analytics — ค้นหาตามเพศ, สีเสื้อ, สีผม, glasses, helmet, bag type; retention 30 วันตามค่าเริ่มต้น

ตลาดเป้าหมาย

Vigil Platform ออกแบบสำหรับ enterprise customers ในเอเชีย โดยเน้น:

  • โรงแรม / Resort: Multiple building, high guest traffic, security + marketing value
  • โรงพยาบาล: 24/7 operations, PDPA sensitive data, multi-department access
  • โรงเรียน / มหาวิทยาลัย: Campus coverage, student safety, PDPA compliance
  • Manufacturing / Warehouse: 100–3,000 cameras, real-time alerts, theft prevention, production monitoring
  • Retail & Shopping Mall: People counting, behavioral analytics, dwell time, occupancy tracking
  • Government / Semi-Government: Data sovereignty (PDPA), white-label, custom integration

วิสัยทัศน์ระยะยาว

Vigil Platform ตั้งมุ่งหมายให้เป็น open-source CCTV analytics platform ที่ครอบคลุมมากที่สุดในเอเชีย โดยอนุญาต SI, reseller, enterprise customers ปรับแต่งและขยายตามความต้องการ นอกจากนี้ยังวางแผนเพิ่มเติม Face Recognition AI (pgvector + InsightFace), vehicle detection, occupancy analytics, BI dashboard integration ในช่วง 6–12 เดือนข้างหน้า
