13 TOR ภาครัฐ (แม่แบบการจัดซื้อจัดจ้าง)

ภาพรวม

ประเทศไทยมี 2 ช่องทางเสนอกลาง: DE (Government Electronic Procurement) และ MDES (Multi-Dimensional Evaluation System) โดย Vigil Platform ออกแบบให้ตอบสนองกับทั้งสองระบบได้

คุณสมบัติหลัก (ตรวจสอบความสอดคล้องจากเทมเพลต TOR)

ข้อกำหนด TOR ความสอดคล้อง Vigil หมายเหตุ
สนับสนุนหลายเวนเดอร์ ✅ Bosch, Hikvision, Dahua, ONVIF (roadmap) ไม่จำกัดเพียงเวนเดอร์เดียว
Thai language UI ✅ Full Thai + English bilingual เมนู รายงาน แจ้งเตือน ทั้งหมดเป็นภาษาไทย
Data residency (PDPA) ✅ ข้อมูลทั้งหมดจัดเก็บในประเทศไทย Self-hosted ไม่มีการส่งออกข้อมูลไปคลาউด
Security audit ✅ SEC-001 ถึง SEC-017 แล้วเสร็จ OWASP Top 10 coverage มีเอกสารประกอบ
Source code access ✅ สามารถขอได้ (escrow option) Proprietary license ไม่ใช่ open-source v1.5.x
Audit log / Accountability ✅ ตาราง audit_logs ครบถ้วน (who, what, when) Immutable records PDPA compliant
Export data format (non-proprietary) ✅ CSV/JSON via API + standard DB access ไม่มี vendor lock-in (สามารถใช้ SQL queries ได้)
Disaster recovery / Backup ✅ Daily automated backup + documented restore procedure ลูกค้ารับผิดชอบการจัดเก็บ offsite
Technical support (Thai) ✅ Email 24 ชั่วโมง + chat 5 วันทำการ (24/7 optional SLA) Dedicated account manager สำหรับสัญญาภาครัฐ
Training + documentation (Thai) ✅ On-site training + Thai documentation 2–5 วันฝึกอบรม (ขึ้นอยู่กับจำนวนพนักงาน)

เกณฑ์การประเมิน TOR ทั่วไป (DE / MDES)

  • Vigil Total: 22/22

โครงสร้างสัญญาภาครัฐทั่วไป

1. HARDWARE & INSTALLATION
   - Server 1 (App + DB): 4C/8GB RAM, 500GB SSD
   - Network switch + cabling (ลูกค้ารับผิดชอบ)
   - Installation labor: 5 วัน SI (รวมในราคา)

2. SOFTWARE LICENSE
   - License 1 ปี (สามารถต่ออายุรายปีได้)
   - Support + updates รวมอยู่
   - 20 กล้อง (ขยายไปถึง 50 ผ่าน "expansion module" purchase)

3. SUPPORT & MAINTENANCE
   - Email 24 ชั่วโมง response (business hours)
   - Software updates quarterly
   - On-site training (2 วัน): admin + operators

4. SLA
   - System uptime: 99% per quarter
   - Critical bug fix: 48 ชั่วโมง response
   - License renewal: 90 วันก่อนหมดอายุ

5. PAYMENT TERMS
   - 30% on contract signed
   - 40% on deployment completion
   - 30% on acceptance (30-day trial period)

จัดการคำคัดค้านสำหรับภาครัฐ

คำคัดค้าน คำตอบ
"ทำไมไม่ได้รับการรับรอง Bosch?" Vigil ปฏิบัติตาม ONVIF ทำงานได้กับกล้องใด ๆ ที่เป็น ONVIF/MQTT ไม่มี vendor lock-in เป็นลักษณะสำหรับภาครัฐ ไม่ใช่ข้อเสีย
"Source code? ความเสี่ยงด้านความปลอดภัย ถ้าปิด" เสนอ source code escrow (บริษัท 3rd party เก็บโค้ด ปล่อยถ้าบริษัทล้มเหลว) Proprietary ช่วยให้ patch security ได้เร็วขึ้น
"บริษัทใหม่ ไม่มีประวัติ" ลูกค้าอ้างอิง (โรงแรม retail ขนาดใหญ่) security audit ผ่านแล้ว (SEC-001–017) warranty 1 ปี + SLA
"ข้อมูลนอกประเทศไทย?" ข้อมูลทั้งหมด self-hosted บนสถานที่ของภาครัฐ ไม่มีการส่งออกข้อมูลไปคลาউด PDPA compliant by design
"ถ้า support จบลง?" ด้วย source code escrow ภาครัฐสามารถบำรุงรักษาได้เองภายใน API stable (backward-compatible) ไม่มี forced upgrades

Checklist ก่อนเสนอโครงการภาครัฐ

  • ☐ เตรียม Thai documentation (SOP, training manual, API reference)
  • ☐ ได้รับ PDPA data processing agreement (DPA) template reviewed โดยทนายความ
  • ☐ หา security audit report (มอบให้กับคณะประเมิน tender)
  • ☐ Setup demo account (TOR evaluators ต้องทำการทดสอบสด)
  • ☐ ระบุ Thai SI partner (ภาครัฐต้องการ local integrator สำหรับ on-site support)
  • ☐ เตรียม reference letters จากลูกค้าปัจจุบัน (ถ้าไม่เป็นความลับ)
  • ☐ มี financial statements + company registration พร้อม (ภาครัฐ due diligence)
  • ☐ ชี้แจง warranty terms + spare parts availability (ความกังวลของภาครัฐ)

Timeline: Government Tender จนถึง Go-live

เดือนที่ 1: TOR published → submit bid + technical proposal
เดือนที่ 2–3: Evaluation โดยคณะ presentation (ถ้า shortlisted)
เดือนที่ 4: Award → sign contract
เดือนที่ 5: Infrastructure setup + training prep
เดือนที่ 6: Deployment + on-site training
เดือนที่ 7: Acceptance test (30-day trial)
เดือนที่ 8: Go-live + handover ให้ government IT team

สำคัญ: ปัจจัยราชการ

Budget approval, procurement board meetings, legal review = ช้ากว่า private sector แผนเวลา 6–12 เดือน ตั้งแต่ RFP ถึง contract signature Early engagement กับ procurement officer ช่วยได้ Partner ด้วย local SI ที่รู้ government processes ในภูมิภาคของคุณ
