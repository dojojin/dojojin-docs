Executive Summary

Vigil Platform มีจุดแข็งชัดในฐานะ on-prem CCTV analytics / security operations platform สำหรับตลาดไทย โดยเฉพาะ LINE alert, Thai/English workflow, health/reporting, audit, PDPA/data ownership, white-label และ multi-vendor event ingestion

Positioning ที่เหมาะ: Security Operations Add-on / Analytics Layer ที่ทำให้กล้องหรือ VMS เดิมฉลาดขึ้นและใช้งานจริงใน operation ไทยได้ดีขึ้น

ไม่ควรวางตัวเป็น full enterprise VMS replacement ในระยะสั้น เพราะตลาดนั้นแข็งมากเรื่อง recording, timeline playback, evidence workflow, storage/failover, device ecosystem, access control และ support maturity

Current Product Shape

ระบบปัจจุบันมีลักษณะเป็น platform มากกว่า dashboard ธรรมดา เพราะมี loop ครบตั้งแต่ camera event ingestion จนถึง alert, report, audit, health, license และ operations

Event-to-action loop Ingest, normalize, snapshot/clip, WebSocket, LINE alert, report history
Operations loop PM2, health page, backup, retention, migrations, audit, service management
Commercial loop License, EULA, white-label, hardware sizing, Thai/English docs
Security loop Auth gates, media protection, audit logs, credential encryption, signed LINE webhook

Strengths

1. Market Fit สำหรับไทยชัดมาก

LINE เป็นช่องทาง alert หลัก มี recipient onboarding, Thai/English UI/report, quiet hours, cooldown, quota visibility และ legal/PDPA posture สำหรับบริบทไทย

2. On-prem และ PDPA/Data Ownership

ระบบเก็บ event, snapshot, media และ credential ภายใน site เป็นหลัก เหมาะกับลูกค้าที่ไม่ต้องการส่ง video หรือ metadata ขึ้น cloud vendor

3. Multi-vendor Event Ingestion ที่มีของจริง

รองรับ Bosch MQTT, Hikvision ISAPI, Dahua CGI และ ONVIF monitor-only พร้อม vendor gotchas ที่มาจาก incident จริง

4. Alert Workflow ครบกว่าระบบทั่วไปในตลาดไทย

LINE subsystem ครอบคลุม rule matching, cooldown, quiet hours, recipient filtering, imgbb, alert logs, quota, pending recipients, block list, camera offline/recovery และ scheduled report delivery

5. Reporting และ Health Monitoring ดีเกินระดับ Dashboard ทั่วไป

มี analytics reports, scheduled reports, health report, report history, PNG/PDF paths, branding, uptime/offline sections และ storage/system warnings

6. Operational Maturity

มี PM2, Service Management UI, Dockerized PostgreSQL/EMQX, fail-fast migrations, backup scripts, retention jobs, health page, camera status logs และ audit logs

Weaknesses and Risks

ยังไม่ใช่ Full VMS ยังไม่เทียบ enterprise VMS ใน recording/playback/evidence workflow/storage failover/deep device management
Scale proof ยังจำกัด Runtime ที่ตรวจได้คือ 7 cameras / 61k events แม้ sizing doc วางไว้ถึง 3,000 cameras
Vendor maintenance burden สูง Firmware/payload/auth/timing quirks เปลี่ยนได้และต้องมีคนดูแลต่อเนื่อง
Codebase complexity api-server.js รับหลาย responsibility และ route จำนวนมาก
Automated test/CI ยังไม่เด่น ยังควรเพิ่ม migration, route, security, alert-engine และ ingester replay tests
Enterprise integration ยังไม่ครบ AD/SSO, SIEM, SMTP, webhook outbound, access control, case management ยังต้องเติม

Recommended Roadmap Priorities

  • SOP per alert rule
  • Alert escalation if unacknowledged
  • Webhook outbound and SMTP
Priority 2: Production hardening
  • Automated smoke test
  • Migration tests
  • Route/security regression tests
  • Off-host backup and restore drill
Priority 3: Scale proof

  • 100/500/1,000 camera benchmark
  • WebSocket fanout benchmark
  • Clip capacity test
Priority 4: Enterprise features

  • Multi-site management
  • SIEM/syslog integration
  • Formal API docs

Business Implication

Vigil Platform มีโอกาสชนะสูงใน niche ที่ชัด เช่น industrial sites, office buildings, retail, schools, Thai security operations teams และ existing CCTV deployments ที่ต้องการ smarter alerts/reports

กลยุทธ์ที่เหมาะที่สุดคือ land-and-expand: เริ่มจาก LINE alerts + health/report overlay, ไม่ disrupt VMS เดิม, แล้วค่อยขยายไป event management, SOP, mobile และ multi-site

Final Assessment

Vigil Platform เป็นระบบที่ดีและมีตลาด ถ้าขายด้วย positioning ที่ถูกต้อง จุดแข็งที่สุดไม่ใช่การเป็น VMS แต่คือการแปลง video analytics event ให้กลายเป็น actionable security operations workflow สำหรับลูกค้าไทย

Vigil ควรเป็นชั้น intelligence/workflow/reporting ที่นั่งบนกล้องและ VMS เดิม ไม่ใช่พยายามเป็น VMS enterprise ทั้งก้อนในระยะสั้น
