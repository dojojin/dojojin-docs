2 · ตัวคุมว่าฟิลด์ไหนทำงาน — carFeatureParam

สิ่งที่เอกสารรุ่นก่อนสรุปว่า "ฟิลด์กลุ่มนี้ส่วนใหญ่ unknown เพราะมุมกล้อง" — จริงแค่บางส่วน · ตัวกำหนดหลักคือสวิตช์บนกล้อง ซึ่งอ่านและเขียนได้จากระบบเรา

อ่าน
GET /ISAPI/ITC/carFeatureParam → XML ~3.2 KB
เขียน
PUT /ISAPI/ITC/carFeatureParam — ส่ง XML ทั้งก้อนกลับโดยแก้เฉพาะฟิลด์ที่ต้องการ

ขั้นตอนที่ใช้จริงและปลอดภัย: GET เก็บ XML เดิมไว้ → แก้ฟิลด์เดียว → ตรวจว่าความยาวเปลี่ยนตามที่คาด (false→true สั้นลง 1 ตัวอักษรพอดี) → PUT → GET อ่านกลับจากกล้อง → เทียบว่าฟิลด์อื่นไม่ขยับ · ขั้นตรวจความยาวเคยกันการเขียน XML เพี้ยนลงกล้องมาแล้วจริง

ถ้าเปิดแล้วไม่ทำงาน
กล้องที่ flag เป็น true อยู่แล้วแต่ยังส่ง unknown เกือบทั้งหมด → reboot (PUT /ISAPI/System/reboot) · กลับมาใน 30–50 วินาที ค่าไม่หาย · พิสูจน์แล้วกับ C10-KAR-SB-04: หมวก 3% → 100% ทันที
