## ข้อ 1 — คำจำกัดความ

ในเอกสารฉบับนี้:

1.1 **"ซอฟต์แวร์"** หมายถึง โปรแกรม DojoJin Tech Dashboard ทุกส่วน
รวมถึงรหัสต้นฉบับ (source code) ไฟล์ปฏิบัติการ (binary) ไฟล์ตั้งค่า
เอกสารประกอบ และส่วนประกอบทั้งหมดที่จัดส่งให้ผู้รับสิทธิ

1.2 **"ผู้ให้สิทธิ"** หมายถึง นายประกาศิต โรจนวิภาส และ/หรือ บุคคล/
นิติบุคคลที่ดำเนินกิจการในชื่อ "DojoJin Tech"

1.3 **"ผู้รับสิทธิ"** หมายถึง บุคคลธรรมดาหรือนิติบุคคลที่ติดตั้งและใช้งาน
ซอฟต์แวร์ภายใต้เอกสารฉบับนี้

1.4 **"License Key"** หมายถึง รหัสลิขสิทธิ์ดิจิทัลที่ผู้ให้สิทธิออกให้แก่
ผู้รับสิทธิ ผูกกับเครื่องเฉพาะ (Machine ID) และมีกำหนดระยะเวลา

1.5 **"เครื่องที่ผูกไว้"** หมายถึง เครื่องคอมพิวเตอร์หรือเซิร์ฟเวอร์ที่
ระบุไว้ใน License Key และเป็นเครื่องเดียวที่ได้รับอนุญาตให้รันซอฟต์แวร์
ภายใต้ License นั้น

1.6 **"ค่าลิขสิทธิ์"** หมายถึง จำนวนเงินที่ผู้รับสิทธิชำระให้แก่ผู้ให้สิทธิ
สำหรับการได้รับ License Key ตามที่ระบุในใบเสนอราคาหรือสัญญาแยกต่างหาก

## ข้อ 2 — การให้สิทธิใช้งาน

2.1 ผู้ให้สิทธิอนุญาตให้ผู้รับสิทธิใช้งานซอฟต์แวร์ภายใต้เงื่อนไขดังนี้:

  (ก) **ไม่ผูกขาด (Non-exclusive)** — ผู้ให้สิทธิยังคงสิทธิที่จะให้สิทธิ
       เดียวกันแก่บุคคลอื่นได้
  (ข) **ไม่อาจโอนสิทธิได้ (Non-transferable)** — ห้ามผู้รับสิทธิโอน
       ขาย ให้เช่า แจกจ่าย หรือมอบสิทธิช่วงให้แก่บุคคลที่สามใดๆ
  (ค) **จำกัดเฉพาะเครื่อง** — ใช้งานได้เฉพาะบนเครื่องที่ผูกไว้
       ตาม Machine ID ใน License Key
  (ง) **จำกัดเวลา** — ใช้งานได้ภายในระยะเวลาที่ระบุใน License Key
  (จ) **เพื่อการใช้งานภายในเท่านั้น** — เพื่อกิจการของผู้รับสิทธิเอง
       ไม่รวมถึงการให้บริการแก่บุคคลที่สาม (Service Bureau) เว้นแต่
       ได้รับอนุญาตเป็นลายลักษณ์อักษรล่วงหน้า

2.2 **ระยะทดลองใช้งาน (Trial Period)** — ผู้รับสิทธิที่ยังไม่ได้
ชำระค่าลิขสิทธิ์ สามารถใช้งานซอฟต์แวร์เป็นระยะเวลา **เจ็ด (7) วัน**
นับจากการเข้าสู่ระบบของผู้ใช้คนแรก เพื่อประเมินผลิตภัณฑ์เท่านั้น
หลังจากครบกำหนด ระบบจะเข้าสู่โหมด "ดูอย่างเดียว" (Read-Only)
จนกว่าจะได้รับ License Key ที่ถูกต้อง

## ข้อ 3 — ข้อจำกัดการใช้งาน (ข้อห้าม)

ผู้รับสิทธิตกลงว่าจะ **ไม่กระทำการ** ดังต่อไปนี้:

3.1 **คัดลอก ทำซ้ำ หรือสำรองข้อมูลซอฟต์แวร์** เพื่อวัตถุประสงค์อื่นนอกเหนือจาก
การสำรองข้อมูลส่วนตัวเพื่อการกู้คืน (Backup) ของเครื่องที่ผูกไว้

3.2 **แจกจ่าย ขาย ให้เช่า ให้ยืม** หรือเผยแพร่ซอฟต์แวร์ทั้งหมดหรือ
บางส่วน ในรูปแบบใดๆ ทั้งสิ้น

3.3 **แก้ไข ดัดแปลง ปรับปรุง** ซอร์สโค้ดของซอฟต์แวร์ เว้นแต่ส่วนที่
ผู้ให้สิทธิระบุชัดว่าสามารถปรับแต่งได้ (ไฟล์ config, branding, ตั้งค่า
รายการกล้อง ฯลฯ)

3.4 **วิศวกรรมย้อนกลับ (Reverse Engineering)** ถอดประกอบ
(Disassemble) หรือถอดรหัส (Decompile) ซอฟต์แวร์ทุกส่วน รวมถึง
การพยายามดึงคีย์ลับ ขั้นตอนวิธี (Algorithm) หรือกลไกการตรวจสอบ
ลิขสิทธิ์

3.5 **เลี่ยง หรือทำลาย กลไกการตรวจสอบลิขสิทธิ์** (License Verification)
รวมถึงการแก้ไขรหัสตรวจสอบลายเซ็น การปลอมแปลง Machine ID
การปลอม License Key หรือกระทำการใดๆ เพื่อใช้งานซอฟต์แวร์โดย
ไม่มีลิขสิทธิ์ที่ถูกต้อง

3.6 **ใช้งานเกินขอบเขต Tier** — เพิ่มจำนวนกล้องเกินจำนวนสูงสุด
ที่ระบุใน License Key หรือใช้ฟีเจอร์ที่ไม่ได้รับอนุญาตในแพ็คเกจ
ที่ชำระเงินไว้

3.7 **ใช้ License Key ของบุคคลอื่น** หรือยอมให้บุคคลที่สามใช้
License Key ของตนเอง

3.8 **ใช้งานในกิจกรรมที่ผิดกฎหมาย** หรือขัดต่อความสงบเรียบร้อย/ศีลธรรม
อันดีของประชาชน รวมถึงการละเมิดสิทธิส่วนบุคคล (Privacy) ของผู้อื่น

## ข้อ 4 — กรรมสิทธิ์ทางปัญญา

4.1 ซอฟต์แวร์และทุกส่วนประกอบเป็นทรัพย์สินทางปัญญาของ
**ผู้ให้สิทธิแต่เพียงผู้เดียว** ภายใต้พระราชบัญญัติลิขสิทธิ์ พ.ศ. 2537
และที่แก้ไขเพิ่มเติม รวมถึงสนธิสัญญาระหว่างประเทศที่ประเทศไทย
เป็นภาคี

4.2 การให้สิทธิตามเอกสารฉบับนี้ เป็นเพียงการ **อนุญาตให้ใช้งาน**
(Licensed) เท่านั้น **ไม่ถือว่าเป็นการโอนกรรมสิทธิ์**
(Not Transferred) แต่อย่างใด ผู้รับสิทธิจะไม่ได้รับสิทธิเป็นเจ้าของ
ในซอฟต์แวร์ ไม่ว่าทั้งหมดหรือบางส่วน

4.3 ชื่อ "DojoJin Tech", โลโก้, เครื่องหมายการค้า, และทรัพย์สินทาง
ปัญญาอื่นๆ ของผู้ให้สิทธิ ยังคงเป็นกรรมสิทธิ์ของผู้ให้สิทธิ ผู้รับสิทธิ
ไม่ได้รับอนุญาตให้ใช้สิ่งเหล่านี้นอกเหนือจากที่ปรากฏในซอฟต์แวร์ที่
ติดตั้ง

4.4 ส่วนที่เป็น **Open Source ของบุคคลที่สาม** ที่รวมอยู่ในซอฟต์แวร์
(เช่น Node.js, PostgreSQL, OpenLayers, Chart.js เป็นต้น) อยู่
ภายใต้สัญญาอนุญาตของผู้พัฒนาเดิม ซึ่งผู้รับสิทธิสามารถดูรายละเอียดได้
จากเอกสารกำกับซอฟต์แวร์

## ข้อ 5 — ระยะเวลาและการสิ้นสุดของสิทธิ

5.1 **ระยะเวลา** — สิทธิตามเอกสารฉบับนี้มีผลตั้งแต่วันที่ผู้รับสิทธิ
Activate License Key และสิ้นสุดในวันที่ระบุใน License Key
(`expires_at`)

5.2 **ระยะผ่อนผัน (Grace Period)** — เมื่อ License หมดอายุแล้ว
ระบบจะอนุญาตให้ใช้งานต่อในโหมด "ดูอย่างเดียว" เป็นเวลา **เจ็ด (7) วัน**
เพื่อให้ผู้รับสิทธิติดต่อต่ออายุ หลังจากนั้นระบบจะปฏิเสธการบันทึก
ทุกประเภทจนกว่าจะมี License Key ใหม่

5.3 **การต่ออายุ (Renewal)** — ผู้รับสิทธิที่ต้องการต่ออายุต้อง
ติดต่อผู้ให้สิทธิและชำระค่าลิขสิทธิ์ตามอัตราที่ผู้ให้สิทธิประกาศใช้
ในขณะนั้น

5.4 **การสิ้นสุดสิทธิโดยอัตโนมัติ** — สิทธิจะสิ้นสุดทันทีโดยอัตโนมัติ
หากผู้รับสิทธิละเมิดข้อใดข้อหนึ่งของเอกสารฉบับนี้ โดยผู้ให้สิทธิไม่
จำเป็นต้องบอกกล่าวล่วงหน้า

5.5 **หน้าที่หลังการสิ้นสุดสิทธิ** — เมื่อสิทธิสิ้นสุดลง (ไม่ว่าด้วย
สาเหตุใด) ผู้รับสิทธิต้อง:
  (ก) **หยุดการใช้งานซอฟต์แวร์ทันที**
  (ข) **ลบหรือทำลายสำเนาของซอฟต์แวร์ทั้งหมด** จากเครื่องและที่
       เก็บข้อมูลของผู้รับสิทธิ
  (ค) **ลบ License Key และคีย์ที่เกี่ยวข้องทั้งหมด**

ทั้งนี้ ข้อมูลที่ผู้รับสิทธิสร้างขึ้นในระหว่างการใช้งาน (เช่น ภาพ
สแน็ปช็อต บันทึก event ฯลฯ) ยังคงเป็นของผู้รับสิทธิ และผู้รับสิทธิ
มีสิทธิดูดข้อมูลออกจากระบบก่อนสิ้นสุดสิทธิ

## ข้อ 6 — การเปลี่ยนแปลงเครื่องที่ผูกไว้

6.1 เนื่องจาก License Key ผูกกับเครื่อง (Machine ID) ที่เฉพาะเจาะจง
หากผู้รับสิทธิจำเป็นต้องย้ายไปใช้งานบนเครื่องอื่น ผู้รับสิทธิจะต้อง
ติดต่อผู้ให้สิทธิเพื่อขอออก License Key ใหม่

6.2 ผู้ให้สิทธิอนุญาตให้ขอ **ออก License Key ใหม่ฟรี (2) สองครั้ง
ต่อปีลิขสิทธิ์** สำหรับกรณีเปลี่ยนเครื่องอันเนื่องมาจาก:
  (ก) ฮาร์ดแวร์เดิมเสียหายหรือเสื่อมสภาพ
  (ข) การย้ายเซิร์ฟเวอร์ตามแผนการขยายงาน
  (ค) เหตุสุดวิสัยที่ไม่อาจหลีกเลี่ยงได้

6.3 การขอออก License Key ใหม่เกินจำนวนที่กำหนด อาจมีค่าธรรมเนียม
ตามอัตราที่ผู้ให้สิทธิประกาศใช้

## ข้อ 7 — ข้อมูลส่วนบุคคล (PDPA)

7.1 ซอฟต์แวร์ติดตั้งบนเซิร์ฟเวอร์ของผู้รับสิทธิ (Self-hosted /
On-premise) **ข้อมูลทุกประเภท** ที่ระบบบันทึก (รวมถึงภาพจาก
กล้องวงจรปิด ข้อมูลส่วนบุคคลที่ปรากฏในภาพ บันทึกเหตุการณ์ ฯลฯ)
**ยังคงเก็บอยู่บนเซิร์ฟเวอร์ของผู้รับสิทธิเอง**

7.2 **ผู้รับสิทธิเป็นผู้ควบคุมข้อมูลส่วนบุคคล** (Data Controller)
ภายใต้พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)
และมีหน้าที่ปฏิบัติตามกฎหมายดังกล่าว รวมถึงการขอความยินยอม
การจัดทำนโยบายความเป็นส่วนตัว การจัดการคำร้องขอจากเจ้าของ
ข้อมูล ฯลฯ

7.3 **ผู้ให้สิทธิไม่เข้าถึงข้อมูลของผู้รับสิทธิ** เว้นแต่กรณีที่ผู้รับสิทธิ
ร้องขอความช่วยเหลือทางเทคนิคและให้ความยินยอมเป็นลายลักษณ์อักษร

7.4 ในกรณีที่ผู้ให้สิทธิเข้าถึงระบบเพื่อให้บริการสนับสนุน ผู้ให้สิทธิ
จะดำเนินการในฐานะ **ผู้ประมวลผลข้อมูลส่วนบุคคล** (Data Processor)
ภายใต้ PDPA และจะรักษาความลับของข้อมูลโดยเคร่งครัด

## ข้อ 8 — การรับประกันและข้อจำกัดความรับผิด

8.1 ซอฟต์แวร์ให้มาในลักษณะ **"AS IS"** (ตามสภาพ) โดยไม่มีการรับ
ประกันใดๆ ทั้งโดยชัดแจ้งหรือโดยปริยาย รวมถึงแต่ไม่จำกัดเพียง การรับ
ประกันความเหมาะสมในการใช้งานเฉพาะด้าน (Fitness for a particular
purpose) ความสามารถในการขาย (Merchantability) หรือการไม่
ละเมิดสิทธิของบุคคลที่สาม

8.2 ผู้ให้สิทธิ **ไม่รับผิด** ต่อความเสียหาย การสูญเสีย หรือผลกระทบ
ทางอ้อม (Consequential / Incidental / Special Damages) ที่
อาจเกิดขึ้นจากการใช้งานหรือไม่สามารถใช้งานซอฟต์แวร์ ไม่ว่าจะใน
ลักษณะใด รวมถึง:
  (ก) การสูญเสียรายได้ ผลกำไร โอกาสทางธุรกิจ
  (ข) การสูญหายของข้อมูล (Data Loss)
