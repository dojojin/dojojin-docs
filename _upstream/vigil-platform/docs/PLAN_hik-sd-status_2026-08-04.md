# แผน — สถานะ microSD ของกล้อง Hikvision (เริ่มที่ HKT)

> สำรวจจริง 2026-08-04 · probe อ่านอย่างเดียวจาก edge ภูเก็ต ไม่แก้ค่าใดบนกล้อง
> สถานะ: **สำรวจเสร็จ · แผนรอไฟเขียว**

---

## 1. คำตอบ: การ์ดที่ใช้ได้เก็บอะไรไว้ — **ไม่ได้เก็บอะไรเลย**

สำรวจ `C22-PT-SB-10` (การ์ด `status=ok` เหลือ 42 GB) ครบทุกมุม:

| ตรวจ | ผล | แปลว่า |
|---|---|---|
| `ContentMgmt/search` วิดีโอ 30 วัน | **`totalMatches = 0` · NO MATCHES** | **ไม่มีวิดีโอสักคลิป** |
| Track 101 (วิดีโอ) | `Enable=true` แต่ **`enableSchedule=false`** | เปิดช่องไว้ แต่**ไม่มีตารางบันทึก → ไม่บันทึก** |
| Track 103 (รูป) | `Enable=true` · `LoopEnable=false` | เปิดไว้แต่ไม่มีอะไรวน |
| `Intelligent/FDLib` (คลังใบหน้า) | **HTTP 403 `notSupport`** | รุ่นนี้ไม่เก็บคลังใบหน้าบนการ์ด |
| พื้นที่ใช้ไป | 60,350 − 41,984 = **18,366 MB** | |

**แล้ว 18 GB คืออะไร?** — เป็น**โครงสร้างที่ Hikvision จองไว้ตอนฟอร์แมต** ไม่ใช่ข้อมูล

หลักฐานชัดที่สุด: **การ์ดทุกใบที่ `status=ok` เหลือว่างเท่ากันเป๊ะ**

```
C22-PT-SB-10  41,984 MB     C81-PT-SB-33  41,984 MB
C42-SKU-SB-17 41,984 MB     C83-PT-SB-34  41,984 MB
C8-PT-SB-05   41,984 MB     C38-PT-SB-17  42,240 MB  (การ์ดใหญ่กว่า 300 MB)
```

ถ้ามีการบันทึกจริง ตัวเลขต้องต่างกันตามปริมาณคนที่ผ่านหน้ากล้องแต่ละจุด
**เหลือเท่ากันหมด = ยังไม่มีใครเขียนอะไรลงไปเลยตั้งแต่ฟอร์แมต** (07-Jul-2026)

### สรุปสถานะการ์ดทั้ง 34 ตัวที่ HKT

| สถานะ | จำนวน | ความหมาย |
|---|---|---|
| `unformatted` | 25 | มีการ์ดแต่ยังไม่ฟอร์แมต — ใช้ไม่ได้ |
| `ok` แต่ **ว่างเปล่า** | 6 | ฟอร์แมตแล้ว แต่ไม่มีตารางบันทึก → ไม่เคยเก็บอะไร |
| `ok` แต่ **เต็ม 0 MB** | 1 (`C56-PKT-SB-17`) | ผิดปกติ ต่างจากพวก — ทีมกำลังตรวจ |
| ไม่มีการ์ด | 2 (`C30`,`C31-CTL-SB-12`) | |

> **ANR:** ไม่มีฟิลด์ ANR ในเฟิร์มแวร์รุ่นนี้ (`/ISAPI/ContentMgmt/record/tracks/101`)
> → ฟอร์แมตการ์ดก็ไม่ได้ replay หลังเน็ตล่ม ได้แค่บันทึกในตัวกล้อง

## 2. ข้อมูลที่ ISAPI ให้ได้ (ทดสอบแล้วว่าตอบจริง)

| Endpoint | ได้อะไร | สถานะ |
|---|---|---|
| `GET /ISAPI/ContentMgmt/Storage` | `status` `capacity` `freeSpace` `property(RW)` `formatType` `encryptionStatus` `installationTime` `workMode` | ✅ 200 |
| `GET /ISAPI/ContentMgmt/record/tracks` | ทุก track: `Enable` `DefaultRecordingMode` `LoopEnable` `enableSchedule` `Duration` + `Description` (codec/ความละเอียด/fps/**bitrate**) | ✅ 200 |
| `POST /ISAPI/ContentMgmt/search` | จำนวนคลิปจริง + ช่วงเวลาเก่าสุด→ใหม่สุด | ✅ 200 |
| `GET /ISAPI/ContentMgmt/Storage/hdd/1/formatStatus` | กำลังฟอร์แมตอยู่ไหม + % | ✅ 200 |
| `GET /ISAPI/Intelligent/FDLib` | คลังใบหน้า | ❌ 403 ไม่รองรับ |
| ฟิลด์ ANR | | ❌ ไม่มีในรุ่นนี้ |

**bitrate 6,144 kbps** จาก `Description` → คำนวณ "บันทึกได้อีกกี่วัน" ได้จริง:
```
41,984 MB ÷ (6,144 kbps ÷ 8 × 3600 × 24 ÷ 1024) MB/วัน  ≈  0.63 วัน
```
> ที่ 4K/1.96fps การ์ด 60 GB บันทึกต่อเนื่องได้แค่ **~15 ชั่วโมง** — ตัวเลขนี้เองก็เป็น
> ข้อมูลที่ผู้ใช้ควรเห็น ก่อนตัดสินใจว่าจะเปิดบันทึกไหม

## 3. แผน 4 Phase

### P1 — เก็บข้อมูลจากกล้อง (backend)

| # | ทำอะไร |

**เกณฑ์เสร็จ:** เรียกกับกล้องจริง 3 ตัว (การ์ดดี / ไม่ฟอร์แมต / ไม่มีการ์ด) ได้ผลถูกทั้ง 3 แบบ

| # | ทำอะไร |

| 2.1 | migration: `sd_detail_json` (jsonb) บน `cameras` — ใช้คอลัมน์เดียวเก็บทุกอย่าง ไม่ต้องเพิ่ม 10 คอลัมน์ |

เป็น query ที่กล้องต้องอ่านดิสก์ ไม่ควรยิงถี่

### P3 — แผงแสดงผล (UI)

แทนที่ข้อความ *"ไม่รองรับการตรวจสถานะ SD — มีเฉพาะกล้อง Bosch"* ในกล่อง
**การบันทึก (SD CARD)** ด้วยของจริง — ใช้ `recBoxProd()` เดิมใน `page-cameras.js`
เพิ่มสาขา Hikvision:

```
การบันทึก (SD CARD)
─────────────────────────────────────────────
สถานะการ์ด    ● ปกติ · อ่าน-เขียนได้ · EXT4 · ไม่ได้เข้ารหัส
ความจุ        ใช้ 18.4 / 60.4 GB  [▓▓▓▓░░░░░░░░░░]  30%
ติดตั้งเมื่อ    7 ก.ค. 2569 11:55

การบันทึก     ⚠ ปิดอยู่ — ไม่ได้ตั้งตารางบันทึก
โหมด          ต่อเนื่อง (CMR) · เขียนวนทับ
คุณภาพ        H.265 · 3840×2160 · 1.96 fps · 6,144 kbps

บันทึกจริง     ไม่มีคลิปในการ์ด (ค้น 30 วันย้อนหลัง)
ถ้าเปิดบันทึก  จะเก็บได้ ~15 ชม. ก่อนเขียนทับ

ANR           ไม่รองรับในรุ่นนี้
ตรวจล่าสุด    4 ส.ค. 2569 19:40
```

**เมื่อมีคลิปจริง** บรรทัด "บันทึกจริง" เปลี่ยนเป็น:
`12–18 ส.ค. (6 วัน · 1,432 คลิป) · เหลือพื้นที่อีก ~2 วัน`

**หลักการออกแบบ:**
- ใช้ `.cm-box` / `.cm-drow` / `.sd-led` ที่มีอยู่แล้ว — ไม่สร้าง component ใหม่
- **แยก "ตั้งค่าไว้ยังไง" กับ "มีอะไรจริง"** ให้ชัด — กล่องเดิมของ Bosch ปนกันจนอ่านยาก
- ค่าที่รุ่นนี้ไม่รองรับ (ANR) **แสดงว่า "ไม่รองรับ" ไม่ใช่ซ่อน** — ไม่งั้นคนจะสงสัยว่าหายไปไหน
- ทุกสี/ระยะจาก token · ตรวจ ≤768px ก่อน commit (WA #2-B)

## 4. สิ่งที่จะ **ไม่** ทำ

- **ไม่ฟอร์แมตการ์ดให้** — เป็นการเขียนลงฮาร์ดแวร์ ต้องเจ้าของสั่ง และทีมกำลังตรวจอยู่
- **ไม่เปิดตารางบันทึก** — เปลี่ยนพฤติกรรมกล้อง ต้องเจ้าของสั่ง
- **ไม่แตะ `C56-PKT-SB-17`** ที่การ์ดเต็ม — ทีมตรวจอยู่

แผงนี้ทำหน้าที่ **บอกความจริง** อย่างเดียว ไม่แก้อะไรให้

## 5. ลำดับที่เสนอ

```
P1 backend    →  P2 เก็บลง DB  →  P3 UI  →  P4 ขยายผล
```
