อนุญาต source 10.0.10.50 ออกไปยัง 202.124.201.106:10001 (TCP)

Edge server รับข้อมูล ANPR (ป้ายทะเบียน) จากกล้องในเครือข่ายเดียวกัน แล้วต้องส่งต่อไปยัง CIB — ปลายทางเดียวกับที่กล้องในเครือข่ายนี้ push ข้อมูลอยู่แล้วทุกวัน (มี policy เดิม ให้กล้องอยู่แล้ว) แต่ Edge server เป็นอุปกรณ์คนละ source IP จากกล้อง จึงยังไม่เคยถูก เพิ่มใน policy ให้ออกไปหาปลายทางนี้

ยิง HTTP POST ว่าง (ไม่มีข้อมูลป้ายทะเบียน) ไปยังปลายทางเดียวกัน จาก 2 เครื่อง:
  จาก Central (184.22.43.1) → HTTP 200
  จากเครื่องนี้ 10.0.10.50 (ออก WAN เป็น 1.10.144.84) → HTTP 403
path / method / header เหมือนกันทุกอย่าง ต่างกันแค่ source IP — ปลายทาง (CIB) ไม่ได้ปฏิเสธ ปัญหาอยู่ที่ policy ขาออกของเครือข่ายนี้

ขอบเขต: ขอเฉพาะ source 10.0.10.50 ไปยัง 202.124.201.106:10001 เท่านั้น ไม่กระทบ policy เดิมของกล้อง/อุปกรณ์อื่นในเครือข่าย และไม่ต้องปรับให้ทั้ง subnet

ทำไมต้องขอแยก กล้อง (camera VLAN) กับ Edge server (10.0.10.50) อยู่ LAN วงเดียวกัน แต่ FortiGate ที่ site นี้คุม policy แบบ per-source-IP (ดูหมายเหตุ "ขอบเขต" ในเอกสารเดิม) — policy ที่อนุญาตกล้องออกไปหา CIB จึงไม่ครอบคลุม Edge server โดยอัตโนมัติ
ไม่กระทบของเดิม กล้องยัง push ตรงไป CIB ตามปกติทุกประการระหว่างที่รอ policy นี้ — คำขอนี้ไม่ได้แตะ หรือย้าย path เดิมของกล้องเลย เป็นแค่การเพิ่มเส้นทางใหม่ให้ Edge server เท่านั้น
