11 Company View (มุมมององค์กร)

รูปแบบเชิงพาณิชย์

ซื้อครั้งเดียว + การดูแลรักษาประจำปี

  • ค่าใบอนุญาต: ขึ้นอยู่กับจำนวนกล้อง + คุณสมบัติ (Profile A/B/C)
  • Maintenance Agreement (MA): 20–25% ของค่าใบอนุญาต ต่อปี
  • สิ่งที่รวมใน MA: การอัปเดตซอฟต์แวร์ แพตช์ความปลอดภัย บริการอีเมลรองรับ 5 วัน/สัปดาห์ เอกสารออนไลน์
  • สิ่งที่ไม่รวม: การพัฒนาคุณสมบัติที่กำหนดเอง (SOW แยก) การรองรับบนไซต์ (ค่าพิเศษ)

รูปแบบรายได้สำหรับ Channel Partners (SI, Resellers)

โครงสร้าง Margin

  • SI/Reseller margin ต่อใบอนุญาต: 30–40% (เทียบกับ SaaS 10–15%)
  • MA passthrough: SI เก็บ 25–30%, Vigil เก็บ 70–75%
  • เหตุผล: SI รับภาระค่าสนับสนุน + ความเสี่ยงของลูกค้า ได้ margin ปีแรกที่เป็นธรรม แต่รายการซ้ำถูก Vigil-driven

รายได้ที่คาดหวังสำหรับ SI

การติดตั้ง 100 กล้องของลูกค้า:

  • ใบอนุญาต: 150K THB (SI margin: 45K)
  • การติดตั้ง + การฝึกอบรม: 20–50K THB (รายได้ SI)
  • ส่วนแบ่ง MA ปีที่ 1: 30K THB × 30% = 9K THB (SI)
  • ปี 2–5 MA: 9K THB/ปี (รายได้ซ้ำ)
  • รวมปีที่ 1: 74K THB | ปี 2–5: 9K THB/ปี แต่ละปี

กลยุทธ์การขายและข้อคัดค้านของลูกค้า

ข้อคัดค้านทั่วไปและการตอบสนอง

  • "ทำไมไม่ใช้ Bosch cloud?" → TCO ต่ำกว่า ข้อมูลอยู่เฉพาะที่ (PDPA) LINE alerts อนาคตหลายเวนเดอร์
  • "จะเกิดอะไรขึ้นหากเราปิดตัวลง?" → ซอร์สโค้ดอยู่ในการควบคุมของลูกค้า (ตัวเลือก open-source ในอนาคต) รองรับชุมชน
  • "ปรับใช้นานแค่ไหน?" → โปรไฟล์ A: 2–3 วัน | โปรไฟล์ B: 1–2 สัปดาห์ | โปรไฟล์ C: 2–4 สัปดาห์ (ขึ้นอยู่กับการตั้งค่าเครือข่าย/storage)
  • "เราต้องมีทีม IT หรือไม่?" → ต่ำสุด: ความรู้พื้นฐาน Docker ops SI จัดการส่วนใหญ่ บริการที่จัดการได้ (Ph.6+)
  • "SLA การสนับสนุน?" → ตอบสนอง 24 ชั่วโมง วันธุรกิจ (MA) สำหรับ SLA 24/7 แพคเกจการสนับสนุนที่กำหนดเอง

การคำนวณ ROI สำหรับลูกค้า

การประหยัดค่าใช้จ่ายเทียบกับ Bosch Cloud

100 กล้อง ขอบเขต 5 ปี:

  • Bosch Cloud: ใบอนุญาต 80K + cloud 100K/ปี = 580K THB
  • Vigil: ใบอนุญาต 150K + MA 30K/ปี = 300K THB
  • การประหยัด: 280K THB (น้อยกว่า 48%)
  • บวกกับ: Data sovereignty ไม่มี vendor lock-in

ประโยชน์การปฏิบัติการ

  • เวลาตอบสนอง: แจ้งเตือนให้ operator ≤3s (เทียบกับอีเมล 5–10 นาที จาก Bosch)
  • ดั้งเดิม LINE: ช่องทางการแจ้งเตือนที่ชอบในประเทศไทย
  • หลายเวนเดอร์: ไม่ต้องซื้ออินฟราสตรัคเจอร์ใหม่เมื่อสลับแบรนด์
  • การวิเคราะห์: ค้นหาซอกหลืบ (Appearances) ข้อมูลพฤติกรรม (Ph.5+)

กลยุทธ์การเข้าสู่ตลาด

ระยะ 1: โดยตรง (ตอนนี้)

  • ลูกค้าเป้าหมายในระบบนิเวศไฮเทคแบงคอก
  • การปรับใช้ POC (ฟรี) สำหรับลูกค้าอ้างอิง
  • การตลาดกรณีศึกษา (โรงแรม + เรื่องสำเร็จการผลิต)

ระยะ 2: SI Channel (Q3 2026)

  • รับสมัครระบบ integrators 3–5 คน (แบงคอก ภูเก็ต เชียงใหม่)
  • โปรแกรมการฝึกอบรม + การรับรอง (bootcamp 2 วัน)
  • การสนับสนุนการขายทางเทคนิค (วิศวกรรมก่อนขาย)
  • การตลาด Co-marketing (SI กรณีศึกษา เหตุการณ์ร่วม)

ระยะ 3: การขยายตัวภูมิภาค (Q4 2026+)

  • คู่ค้าเวียดนาม อินโดนีเซีย ฟิลิปปินส์
  • การแปลเป็นภาษาท้องถิ่น: i18n (VI, ID, MS) การชำระเงินท้องถิ่น การสนับสนุนท้องถิ่น

การติดตั้งและการเข้าเบิก

ไทม์ไลน์โครงการทั่วไป

สัปดาห์ 1: ความต้องการ → ลงนามใน SOW → เตรียมโครงสร้างพื้นฐาน (VM/Docker host พร้อม)
สัปดาห์ 2: ปรับใช้แพลตฟอร์ม → กำหนดค่ากล้อง (Bosch MQTT setup, Hik/Dahua credentials)
สัปดาห์ 3: การทดสอบ + การฝึกอบรมผู้ใช้ → walkthroughs ผู้ดูแลระบบ + operator
สัปดาห์ 4: Go-live + shadowing 1 สัปดาห์ (SI บนไซต์หรือระยะไกล)
สัปดาห์ 5–12: feedback loop, performance tuning, knowledge transfer ให้ customer IT

การมอบหมายให้ลูกค้า

  • เอกสาร (wiki + บทช่วยสอนวิดีโอ)
  • Playbook ผู้ดูแลระบบ (ops ประจำวัน backup อัปเดต)
  • ติดต่อการสนับสนุน + ระบบตั๋ว
  • การทบทวนธุรกิจรายไตรมาส (KPI การใช้งาน การจัดตำแหน่งแผนงาน)

อนาคต: ตัวเลือกบริการที่จัดการ (Ph.6)

สำหรับลูกค้าที่ไม่มีทรัพยากร IT ให้บริการตัวเลือก cloud-hosted (Vigil as a Service) ซึ่งเราจัดการโครงสร้างพื้นฐาน + การสนับสนุน 24/7 Margin ที่สูงขึ้น ลูกค้าไม่รับกระแทก แต่ต้องใช้สถาปัตยกรรม multi-tenant + การปรับขนาดการปฏิบัติตาม
