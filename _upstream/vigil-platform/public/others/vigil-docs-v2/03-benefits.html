03 4P · SWOT · จุดเด่น

4P Analysis (Product, Price, Place, Promotion)

Product (สินค้า)

Vigil Platform — Self-hosted CCTV Analytics ที่เอาใจใส่:

  • Multi-vendor support (Bosch, Hikvision, Dahua, ONVIF)
  • Real-time LINE alerts with snapshot
  • Security Morning Briefing (Executive Summary) dashboard
  • Health Report (PNG report ภาษาไทย/อังกฤษ)
  • Mobile app (iOS + Android, React Native)
  • Appearances Analytics (forensic search, behavioral analytics)
  • Smart map (OpenLayers, CartoDB tiles)
  • Bilingual UI (TH/EN)
  • PDPA compliant, data sovereignty (local storage)

Price (ราคา)

Business Model: One-time license + annual maintenance

  • Profile A (10–50 cameras): ~50–80K THB (one-time) + 20–30K THB/year MA
  • Profile B (50–500 cameras): ~100–150K THB + 30–50K THB/year MA
  • Profile C (500–3,000 cameras): ~200–400K THB + 50–100K THB/year MA
  • Add-on: Customization, Face Recognition (Ph.5+), integration, SLA support

vs. SaaS: Vigil = lower TCO ที่มีความเสถียรสูง + no monthly recurring fixed cost + data ownership

Place (ช่องทางจัดจำหน่าย)

  • Direct B2B: Large enterprise (hotel, hospital, manufacturing, government)
  • Channel: System Integrator (SI), CCTV distributors, Bosch reseller network
  • White-label: SI rebrand → ลูกค้าปลายทางเห็นแบรนด์ SI เท่านั้น
  • Geographic: Thailand, Southeast Asia, eventually Asia-Pacific

Promotion (การส่งเสริม)

  • Live Docs + case study (บริษัทสหภาพที่ใช้ Vigil แล้ว)
  • Free trial / POC (Proof of Concept) deployment ที่ลูกค้า
  • Training + certification program สำหรับ SI/partners
  • Roadshow / webinar ตลาด industrial, retail, government
  • GitHub + open-source positioning (when applicable)

SWOT Analysis

Strengths (จุดแข็ง)

  • Multi-vendor agnostic — รองรับ 3+ ยี่ห้อได้ code-level ไม่ hardcoded
  • Data sovereignty — ไทยที่หลัก, PDPA-ready, no vendor lock-in
  • Real LINE integration — ตลาดไทย expectation
  • Mobile app — iOS + Android, native performance, biometric auth
  • Proven security audit — SEC-001–017 passed, OWASP coverage
  • White-label ready — SI margin control, branding flexibility
  • Source code ownership — differentiate vs SaaS lock-in
  • Modular codebase — Backend แยก 19 route modules + Frontend แยก 21 page files; แก้ bug เร็ว ต่อเติมง่าย ความเสี่ยงต่ำเมื่อปรับแต่งสำหรับ white-label

Weaknesses (จุดอ่อน)

  • Not SaaS — deployment complexity, IT skill requirement สูง
  • Early market — brand awareness ต่ำเทียบ Bosch/Hikvision cloud
  • Manual deployment — no managed service option yet (Roadmap Ph.6+)
  • Limited ONVIF — Phase 4 feature, not available in v1.5
  • Face Recognition — not yet released (Ph.5)
  • Small engineering team — rapid feature release ช้าเทียบ cloud products

Opportunities (โอกาส)

  • Government procurement — PDPA + data sovereignty = key requirement
  • Regional expansion — ASEAN market (Vietnam, Indonesia, Philippines)
  • IoT integration — smart building, occupancy, access control
  • Face Recognition boom — Ph.5 will unlock forensic/behavioral use cases
  • AI+video analytics — vehicle detection, crowd counting (Roadmap)
  • Channel partner network — franchise SI model
  • BI integration — Tableau, Power BI partnership (Ph.6+)

Threats (ภัยคุกคาม)

  • Bosch cloud pricing competitive — aggressive discount can kill margin
  • Cloud providers (AWS, Azure, GCP) — partner with camera vendors
  • Open-source competitors — ZoneMinder, Shinobi (small but growing)
  • Hikvision bundled cloud — free/cheap cloud option from camera vendor
  • Talent retention — startup salary vs product company
  • Regulatory uncertainty — PDPA enforcement changes, data law evolution

Positioning Statement

Vigil Platform คือ self-hosted CCTV analytics platform สำหรับ enterprise ที่ต้องการ data sovereignty, multi-vendor flexibility, LINE alerts, และ white-label branding โดยไม่ต้องพึ่งพา vendor cloud ที่เสียค่าใช้จ่ายสูงหรือล็อกข้อมูลไว้ต่างประเทศ
