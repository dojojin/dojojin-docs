Deployment Profile Summary

Profile A

Events + Rules

Single server, 10–50 cameras, events only (no snapshots), analytics dashboard, alerts

  • Bosch/Hik/Dahua ingest
  • Timeline view
  • LINE alerts
  • Health Report

Profile B

A + Snapshots

Single server + storage, 50–500 cameras, with snapshot caching, pre-alarm video ±10s

  • Everything in A
  • Snapshot gallery
  • Pre-alarm video
  • Face capture (Hik)

Profile C

Full Recording

2-tier or HA deployment, 500–3,000 cameras, complete video recording, clustering

  • Everything in B
  • Full video record
  • Appearances search
  • Advanced analytics
