14 วิเคราะห์ลักษณะบุคคล

คืออะไร? — ระบบบันทึกและค้นหาบุคคลจากลักษณะภายนอก เช่น เพศ สีเสื้อ ทรงผม แว่นตา กระเป๋า โดยอ่านข้อมูลจากกล้อง Bosch IVA Pro ที่ส่งมาพร้อมกับ event แบบอัตโนมัติ ไม่ต้องกรอกข้อมูลเอง

ทำงานอย่างไร?

เมื่อกล้อง Bosch IVA Pro ตรวจจับบุคคลหรือยานพาหนะ ระบบจะส่งข้อมูล event มาพร้อมกับ "ลักษณะที่ตรวจพบ" เช่น เพศ กลุ่มอายุ สีเสื้อ Vigil Platform รับข้อมูลนี้ผ่าน MQTT แล้วบันทึกลงฐานข้อมูลทันที ผู้ใช้สามารถเปิดหน้า "ลักษณะบุคคล" บนแดชบอร์ดเพื่อดูกราฟสถิติหรือค้นหาย้อนหลังได้ทันที

ข้อมูลที่บันทึก

  • เพศ (ชาย / หญิง)
  • กลุ่มอายุ (เด็ก / วัยรุ่น / ผู้ใหญ่ / ผู้สูงอายุ)
  • ประเภทและสีเสื้อชั้นบน
  • ประเภทและสีเสื้อชั้นล่าง
  • ความยาวและสีผม
  • แว่นตา (ใส่ / ไม่ใส่)
  • หมวกหรือหมวกกันน็อก
  • ประเภทกระเป๋า (เป้ / ถือ / ไม่มี)
  • เสื้อกั๊ก (เสื้อนิรภัย / อื่นๆ)
  • ประเภทและสียานพาหนะ (ถ้ามี)

แหล่งข้อมูล

ข้อมูลลักษณะบุคคลมาจาก Bosch IVA Pro ซึ่งวิเคราะห์ภาพจากกล้องแบบ real-time แล้วแนบ metadata มากับ event

Vigil Platform ไม่ได้ประมวลผลภาพเอง — ทำหน้าที่รับ จัดเก็บ และแสดงผลข้อมูลที่กล้องส่งมาเท่านั้น

หมายเหตุ: ความแม่นยำขึ้นอยู่กับความละเอียดกล้อง มุมกล้อง และแสงสว่าง ณ จุดติดตั้ง

หน้าจอที่ใช้งาน

หน้า "ลักษณะบุคคล" บนแดชบอร์ดมี 2 แท็บหลัก:

แท็บที่ 1 — ภาพรวมสถิติ

แสดงกราฟสรุปพฤติกรรมของบุคคลที่ตรวจจับได้ในช่วงเวลาที่เลือก (ค่าเริ่มต้น: 7 วันล่าสุด) สามารถกรองตามกล้องและช่วงวันเวลาได้

กราฟสัดส่วนเพศ

แผนภูมิวงกลมแสดงสัดส่วนชาย / หญิง ของบุคคลที่ตรวจพบ

ใช้วิเคราะห์กลุ่มผู้เข้าชมสำหรับห้างหรือสถานที่เชิงพาณิชย์

กราฟประเภทเสื้อชั้นบน

แผนภูมิแท่งแนวนอนแสดงอันดับประเภทเสื้อที่พบบ่อยที่สุด เช่น เสื้อเชิ้ต แจ็คเก็ต เสื้อยืด

วิเคราะห์แนวโน้มการแต่งกายตามฤดูกาล

กราฟประเภทเสื้อชั้นล่าง

แผนภูมิแท่งแนวนอนแสดงอันดับประเภทชั้นล่างที่พบบ่อย เช่น กางเกงขายาว กางเกงขาสั้น กระโปรง

ข้อมูลเดียวกัน แต่สำหรับส่วนล่างของร่างกาย

กราฟความยาวผม

แผนภูมิแท่งแนวนอนแสดงสัดส่วนผมสั้น / กลาง / ยาว

ใช้ประกอบการค้นหาตัวบุคคลในกรณีสอบสวน

กราฟปริมาณตรวจพบตามเวลา

กราฟเส้นแสดงจำนวนคนที่ตรวจพบในแต่ละช่วงเวลา ตลอด 7 วัน

ดูช่วง peak hour และ pattern การเข้า-ออก

แถบสีเสื้อและผม

แสดง 5 สียอดนิยมของเสื้อชั้นบน เสื้อชั้นล่าง และผม เป็นแถบสีจริงให้อ่านง่าย

อ้างอิงสีด่วนโดยไม่ต้องจำชื่อสี

แท็บที่ 2 — ค้นหาบุคคล

ค้นหาเหตุการณ์ย้อนหลังโดยใช้ลักษณะบุคคลเป็น filter ผลลัพธ์แสดงเป็น grid ของ event card พร้อมภาพ snapshot กดเพื่อดูรายละเอียดและวิดีโอย้อนหลัง

กรณีการใช้งาน

สอบสวนเหตุการณ์

เมื่อเกิดเหตุ เช่น ของหาย หรือบุคคลต้องสงสัย ใช้ลักษณะที่จำได้มาค้นหาย้อนหลัง ลดเวลาดูวิดีโอจากชั่วโมงเหลือนาที

วิเคราะห์ผู้เข้าชม (ห้าง / อาคาร)

สัดส่วนเพศ กลุ่มอายุ ช่วง peak hour — ใช้วางแผนการจัดพนักงาน โปรโมชัน และพื้นที่

ติดตามบุคคลสูญหาย

"เด็กผู้หญิง ใส่เสื้อสีชมพู กางเกงสีขาว" — ค้นหาย้อนหลังจากทุกกล้องพร้อมกันได้ทันที

ตรวจสอบการปฏิบัติตามกฎ

พื้นที่โรงงานกำหนดให้ใส่เสื้อกั๊กนิรภัย — ระบบนับและแจ้งเตือนเมื่อพบบุคคลที่ไม่ใส่

วิเคราะห์แนวโน้มการแต่งกาย

ข้อมูลสถิติรายเดือน เช่น เสื้อแจ็คเก็ตพีคช่วงหน้าหนาว เสื้อยืดและกางเกงขาสั้นพีคหน้าร้อน

ของหาย

"บุคคลใส่เสื้อกั๊กสีส้ม พร้อมเป้สะพายหลังสีดำ" — ระบุตัวบุคคลเพื่อส่งคืนสิ่งของได้โดยไม่ต้องดูวิดีโอทั้งหมด

การเก็บข้อมูลและ PDPA

ระยะเวลาเก็บข้อมูล

  • ค่าเริ่มต้น: 30 วัน
  • ปรับได้สูงสุด: 730 วัน (2 ปี)
  • ตั้งค่าได้ที่: Settings › การเก็บข้อมูล
  • ลบอัตโนมัติตาม schedule — ไม่ต้องทำเอง

สิทธิ์ตาม PDPA

  • ผู้ใช้ขอลบข้อมูลของตน → Admin ลบได้ทันที
  • ข้อมูลไม่ถูกส่งออกไปยัง Cloud ภายนอก — เก็บบนเซิร์ฟเวอร์ลูกค้า
  • ไม่มีการจดจำใบหน้า — บันทึกแค่ลักษณะภายนอก ไม่ใช่ biometric
  • แนะนำติดป้ายแจ้งการบันทึกภาพตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล

Phase 5 — Face Recognition AI
