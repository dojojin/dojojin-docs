01 — Topology ปัจจุบัน (As-Is)

ผังการเชื่อมต่อจริง ณ ตอนนี้ — VSS = Edge site

VSS เป็น edge site จริงแล้ว ไม่ใช่ single-box — กล้อง 8 ตัว (192.168.10.x) เข้า N150 (192.168.10.30, EDGE_MODE=1): Hik/Dahua ถูก N150 poll, Bosch publish เข้า NanoMQ บน N150, FaceReg push เข้า FAS. ingester ทุกตัว ไม่เขียน Postgres local — publish เข้า NanoMQ → edge-bridge (edge-vss) → WSS → MacBook central (EMQX → mqtt-subscriber → Postgres). ภาพเก็บที่ N150 (Tier-2), central ดึง on-demand ผ่าน proxy. Main Site (ภูเก็ต 10.x) push ผ่าน Cloudflare — ตอนนี้ paused.

Edge ingest → NanoMQ → bridge MQTT (Bosch / EMQX) DB / LINE Face / Mobile proxy / vestigial
VSS = edge จริง (ยืนยันจาก N150): EDGE_MODE=1 · EDGE_SITE_ID=vss · NanoMQ รัน (ไม่มี EMQX บน N150) · bridge remote=up forwarded=137 dropped=0. กล้องทุกตัวเข้า N150 → NanoMQ → bridge → central EMQX — N150 เป็น ingest จุดเดียวของ VSS.
Double-ingest = ความเสี่ยงต่ำ: MacBook อยู่ subnet 192.168.31.x เข้ากล้อง 192.168.10.x ไม่ถึง → ingester hikvision/dahua บน MacBook poll ไม่ได้ (vestigial — ควร disable). เส้นทางเดียวที่ VSS event เข้า central = ผ่าน edge-vss bridge.

06 — แผนอนาคต

N150 Edge → WireGuard → Cloud (Multi-Site)

ย้ายจาก single-box ไปเป็น edge ต่อ site + cloud กลาง. กล้องอยู่หลัง edge (N150), edge ต่อ cloud ผ่าน WireGuard (ไม่ใช่ Cloudflare tunnel สำหรับ cloud). ภาพ full-res เก็บที่ edge — ขึ้น cloud เฉพาะ metadata + thumbnail. สถานะ: Design เสร็จ · Phase 0 POC · Phase 1 (Bangmod.Cloud) รอ deploy
