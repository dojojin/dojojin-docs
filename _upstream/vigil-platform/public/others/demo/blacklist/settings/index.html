LIVE DEMO — เชื่อมต่อจริง 3 จาก 8 ประเภท (Dahua DSS Pro-Face / GuruSquare-LPR / Dahua NVR/กล้อง-Face+LPR ผ่าน Edge Site HDY) — credential ที่กรอกใช้ทดสอบครั้งเดียวเท่านั้น ไม่ถูกบันทึกที่ไหนเลย (ยังไม่มี schema ฐานข้อมูล blacklist จริงให้เก็บ) — รายการเชื่อมต่อที่เพิ่ม/แก้ไขในหน้านี้ก็อยู่ในเบราว์เซอร์เซสชันนี้เท่านั้น · ผลลัพธ์ที่แสดงถูกปิดบังเลขบัตร/ข้อมูลเจ้าของเสมอ เป็นการพิสูจน์ว่าเชื่อมต่อได้และรูปแบบข้อมูลถูกต้อง ไม่ใช่การดึงข้อมูลเต็มมาโชว์ · หน้านี้จำกัดเฉพาะ admin · อีก 5 ประเภท (HCP / OpenAPI มาตรฐาน / CSV / กรอกเอง / Hikvision NVR) เป็น UI ที่ออกแบบรอไว้ก่อน ยังไม่เชื่อมจริง

ตั้งค่านำเข้าข้อมูล Blacklist
