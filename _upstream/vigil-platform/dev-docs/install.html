คู่มือติดตั้งระบบ — From Zero to Running

ครอบคลุมการติดตั้งบน macOS (เครื่อง owner) และ Linux server ใหม่ทั้งหมด — ตั้งแต่ clone จนถึง login ครั้งแรก

สำหรับ daily start/stop ใช้ Restart Services แทน

หน้านี้คือ from-scratch install เท่านั้น — ถ้าระบบ install อยู่แล้วและต้องการแค่ restart ดูที่ Restart Services (LNP)

Prerequisites

สิ่งที่ต้องมีเวอร์ชันวิธีเช็ค
macOS / LinuxmacOS 12+ หรือ Ubuntu 22.04+sw_vers หรือ lsb_release -a
Node.js18+node --version
npm9+npm --version
Docker Desktop4.x+docker --version
PM25+pm2 --version (install: npm i -g pm2)
Git2.x+git --version
CamerasBosch MQTT / Hikvision ISAPI / Dahua CGI—

ขั้นตอนติดตั้ง (8 ขั้นตอน)

1

Clone repository

git clone <repo-url> vigil-platform
cd vigil-platform
2

ตั้งค่า Environment Variables

cp .env.example .env
nano .env   # แก้ค่าเหล่านี้:
            # DB_PASSWORD — รหัสผ่าน PostgreSQL
            # SESSION_SECRET — random 32 bytes (ดูขั้นตอน 3)
            # MAPBOX_TOKEN — สำหรับ map page (ขอได้ที่ mapbox.com)
            # LINE_CHANNEL_ACCESS_TOKEN — สำหรับ LINE alerts (ถ้าใช้)
# Generate SESSION_SECRET
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
3

เริ่ม Docker services (PostgreSQL + EMQX)

docker compose up -d
# ตรวจสอบ:
docker ps   # ควรเห็น vigil-postgres + vigil-emqx สถานะ "Up"

EMQX = MQTT broker เท่านั้น

อย่าสับสนกับ Mosquitto — ระบบใช้ EMQX 5.8 เพราะ Mosquitto 2.x reject packet บางรูปแบบของ Bosch (GOTCHAS #33)

4

Initialize database

# Init schema (ทำครั้งเดียวบน volume ใหม่)
docker exec -i vigil-postgres psql -U vigil_sql -d vigil_platform < db/init.sql

# ตรวจสอบ — ควรเห็น 14+ tables
docker exec -it vigil-postgres psql -U vigil_sql -d vigil_platform -c "\dt"

Volume เก่า — ไม่ต้อง init ซ้ำ

ถ้า volume มีข้อมูลอยู่แล้ว ไม่ต้อง init ซ้ำ — schema migration จะ apply อัตโนมัติเมื่อ api-server boot (ขั้นตอน 6)

5

Install Node.js dependencies

cd src && npm ci
cd ..   # กลับ repo root
6

Start services ด้วย PM2

LNP Trap — ต้องรันจาก macOS GUI Terminal เท่านั้น

ห้ามรันจาก tmux / SSH / Claude shell — กล้อง Bosch จะ disconnect (GOTCHAS #84) ดู Restart Services

# วิธีที่ 1 — ผ่าน .command script (แนะนำ)
open -a Terminal /Users/dojojin/vigil-platform/scripts/pm2-lan-safe-restart.command

# วิธีที่ 2 — PM2 โดยตรง (ใน macOS GUI Terminal)
pm2 start ecosystem.config.js

# ตรวจสอบ
pm2 status
# ควรเห็น 7 workers: api-server, mqtt-subscriber, hikvision-isapi,
# dahua-cgi, media-recorder, alert-worker, report-worker

ครั้งแรก api-server boot — migrate.js จะ apply schema migrations อัตโนมัติ ดู log ได้ที่:

pm2 logs api-server --lines 50
7

ตั้ง PM2 autostart (launchd)

# ตั้งครั้งเดียว — PM2 จะ start อัตโนมัติเมื่อ reboot
pm2 startup
# รัน command ที่ PM2 แสดงออกมา (sudo ...)

pm2 save   # บันทึก process list ปัจจุบัน
8

เข้าใช้งานครั้งแรก

# Local
open http://localhost:3000

# Flow: /disclaimer.html → /login.html → /
# Default credentials:
#   Username: admin
#   Password: changeme  (ระบบบังคับเปลี่ยนรหัสครั้งแรก)

Production Deploy — Cloudflare Tunnel

ข้ามได้ถ้า local-only

ถ้าใช้งานเฉพาะ LAN ข้ามหัวข้อนี้ได้ — ไม่ต้อง public domain

# ติดตั้ง cloudflared
brew install cloudflared   # macOS
# หรือ wget/dpkg สำหรับ Linux

# Login + สร้าง tunnel
cloudflared tunnel login
cloudflared tunnel create vigil-platform
cloudflared tunnel route dns vigil-platform dashboard.yourdomain.com

# Config ไฟล์ (~/.cloudflared/config.yml)
# tunnel: <tunnel-id>
# credentials-file: ~/.cloudflared/<tunnel-id>.json
# ingress:
#   - hostname: dashboard.yourdomain.com
#     service: http://localhost:3000
#   - service: http_status:404

# เริ่ม tunnel
cloudflared tunnel run vigil-platform

Migration จาก Version เก่า

# 1. Backup ก่อนเสมอ
./scripts/backup.sh

# 2. Schema migrations apply อัตโนมัติเมื่อ api-server boot
pm2 restart api-server
pm2 logs api-server --lines 30   # ดู "Migration applied: ..."

# Manual run (ถ้าต้องการรันก่อน)
cd src && npm run migrate

Migration fail = api-server ไม่ start (by design)

ถ้า migration error → ไม่ comment out → restore backup แล้วแก้ SQL ให้ถูกต้อง (GOTCHAS #19)

Backup / Restore

# Backup manual
./scripts/backup.sh   # → backups/vigil_platform_YYYY-MM-DD_hhmmss.dump

# ตั้ง daily auto-backup (launchd)
cp scripts/com.dojojin.dashboard.backup.plist ~/Library/LaunchAgents/
launchctl load -w ~/Library/LaunchAgents/com.dojojin.dashboard.backup.plist

# Restore
./scripts/restore.sh backups/vigil_platform_2026-05-29_030000.dump

pg_dump -Fc ไม่ใช่ plain SQL

cat backup.dump จะเห็น binary — ใช้ pg_restore --list เพื่อดู TOC (GOTCHAS #20)
