Recipe: เพิ่ม i18n String

Dashboard รองรับ 2 ภาษา (Thai / English) ผ่าน dashboard/i18n.js ที่ expose I18N object ทุกไฟล์ใน index.html

GOTCHAS #42 — ต้องใส่ทั้ง th และ en เสมอ

ถ้าใส่แค่ th: ไม่ใส่ en: — เมื่อ user เปลี่ยน language เป็น English จะเห็น undefined ในหน้า UI

ขั้นตอน

1

เปิด dashboard/i18n.js — DICT object มีโครงสร้าง:

var DICT = {
  th: {
    'existing.key': 'ข้อความไทย',
    // ... หลายร้อย keys
  },
  en: {
    'existing.key': 'English text',
    // ...
  }
};
2

เพิ่ม key ใหม่ใน ทั้ง 2 blocks — key ต้องเหมือนกันทุกตัวอักษร:

var DICT = {
  th: {
    // ... existing keys ...
    'myfeature.title':     'ชื่อ Feature ของฉัน',
    'myfeature.save':      'บันทึก',
    'myfeature.noData':    'ไม่มีข้อมูล',
  },
  en: {
    // ... existing keys ...
    'myfeature.title':     'My Feature',
    'myfeature.save':      'Save',
    'myfeature.noData':    'No data',
  }
};
3

ใช้ใน dashboard/dashboard.js หรือไฟล์ JS อื่น:

// Dynamic string (JavaScript)
element.textContent = I18N.t('myfeature.title');

// ใน HTML string (innerHTML)
html += `<h2>${I18N.t('myfeature.title')}</h2>`;

// ใน template literal
const label = I18N.t('myfeature.save');
4

หรือใช้ data-i18n attribute สำหรับ static markup ใน HTML file:

<!-- textContent -->
<h2 data-i18n="myfeature.title"></h2>

<!-- innerHTML (ถ้า value มี HTML tag) -->
<p data-i18n-html="myfeature.description"></p>

<!-- placeholder -->
<input data-i18n-ph="myfeature.placeholder">

Key Naming Convention

Patternใช้กับตัวอย่าง
nav.xxx sidebar nav items nav.summary, nav.cameras
page.xxx page titles page.events, page.health
set.xxx settings section set.users, set.backup
login.xxx login page login.username
aux.xxx shared UI components aux.searchPlaceholder, aux.noMatchItems
myfeature.xxx feature-specific strings ใช้ namespace ของ feature

เช็ค: ค้น key ที่มีอยู่แล้ว

# ค้น key ที่ขึ้นต้นด้วย namespace
grep "'myfeature\." dashboard/i18n.js

# ดู key ทั้งหมดใน th block
grep -A9999 "^  th:" dashboard/i18n.js | grep -B9999 "^  en:" | grep "'"

Thai เป็น source language

Thai คือ source — ถ้าไม่แน่ใจว่า English translation ควรเป็นอะไร ใส่ English ที่เข้าใจง่ายไปก่อน ไม่ใช้ Google Translate ตรงๆ สำหรับ technical terms
